# S K STUDIO – Fashion Store

## About the Project

S K STUDIO is a simple and stylish online fashion shopping website. It allows users to explore different fashion products, including clothing, footwear, and accessories.

The website is designed with a clean layout and user-friendly interface to provide a smooth shopping experience.

## Features

- Modern and attractive homepage
- New Arrivals section
- Clothing collection
- Footwear collection
- Accessories collection
- Product prices and discounts
- Add to Bag functionality
- Shopping cart
- Simple and user-friendly interface
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
fashionstudio-website/
│
├── index.html

```

## How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/shubhamk060405-lab/fashionstudio-website.git
```

2. Navigate to the project folder:

```bash
cd fashionstudio-website
```

3. Open the `index.html` file in your web browser.

## Project Purpose

The main purpose of this project is to improve frontend development skills and gain practical experience in building a fashion shopping website using HTML, CSS, and JavaScript.
